# SafeBox – Coffre sécurisé intelligent

**Cours :** 420-314 – Programmation de plateformes embarquées (Automne 2026), Cégep Marie-Victorin
**Équipe :** Akli Tamani, Nathanael Jules Mugara
**Plateforme :** Arduino Nano ESP32 (ABX00083), MicroPython

## Description

Coffre qui s'ouvre avec un badge RFID (RC522) ou un code entré à l'encodeur rotatif, avec détection de présence (PIR), détection d'ouverture (photorésistance), alarme et blocage après 3 échecs.
